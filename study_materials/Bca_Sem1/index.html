How to use this guide

Discrete mathematics studies objects that can be separated and counted, along with the precise rules connecting them. It supports reasoning used in computer science: conditions, data groups, mappings, networks and systems of equations.

Study sequence: understand the definition → read the notation → work a small example → practise a new example → explain why the answer is correct.

This guide follows the supplied Mahatma Gandhi University syllabus for MG1DSCBCA103. It preserves the module order and stated scope. The ESE carries 70 marks and CCA carries 30 marks. Practice questions here are syllabus-based, not claimed to be actual or guaranteed MGU questions.

Course outcomes in plain language

  • Understand and solve problems involving sets.
  • Understand propositional logic, apply operators, truth tables and inference rules.
  • Analyse relations, functions and equivalence relations.
  • Understand matrices and operations; find inverses and solve non-homogeneous linear systems using matrix methods and Cramer’s rule.

MODULE 1 · LOGIC AND PROOFS · 15 HOURS

Propositional logic, equivalences and inference

You will learn: propositions, logical connectives, propositional equivalences and rules of inference.

Why it matters: computers and mathematical arguments depend on precise statements and reliable ways of combining or deriving them.

1.1 Propositional logic

A proposition is a declarative statement that is either true or false. Let p and q be propositions. The main connectives are:

SymbolNameSimple meaning
¬pNegationNot p
p ∧ qConjunctionp and q; true only when both are true
p ∨ qDisjunctionp or q (inclusive); true when at least one is true
p → qConditionalIf p, then q; false only when p is true and q false
p ↔ qBiconditionalp if and only if q; true when they have the same truth value
Truth table for conditional p → q
pqp→q
TTT
TFF
FTT
FFT

A conditional is considered true when its premise p is false because it makes no false promise about the case “if p.” This truth-table rule is important even if it feels unfamiliar at first.

1.2 Propositional equivalences

Two propositions are logically equivalent if they have the same truth value for every assignment of truth values. Write p≡q. Truth tables can verify equivalence.

Double negation: ¬(¬p) ≡ p
De Morgan: ¬(p∧q) ≡ (¬p∨¬q);   ¬(p∨q) ≡ (¬p∧¬q)
Implication: p→q ≡ ¬p∨q
Contrapositive: p→q ≡ ¬q→¬p

Other useful laws include commutative, associative, distributive, identity and domination laws. Use the law names and forms taught in class; transform one expression at a time and keep brackets clear.

Step-by-step equivalence: Simplify ¬(p∧q). By De Morgan’s law, replace “not (p and q)” with “not p or not q”: ¬p∨¬q. In words, it is enough for at least one of p or q to be false.

1.3 Rules of inference

A rule of inference is a valid pattern for deriving a conclusion from premises. An argument is valid if whenever its premises are true, its conclusion must be true.

RulePatternPlain-language cue
Modus ponensp, p→q ∴ qp holds; p guarantees q; therefore q
Modus tollens¬q, p→q ∴ ¬pq did not happen; so the sufficient condition p did not hold
Hypothetical syllogismp→q, q→r ∴ p→rChain implications
Disjunctive syllogismp∨q, ¬p ∴ qOne of p or q; rule out p
Common mistake: affirming the consequent (p→q, q, therefore p) is invalid. q might be true for another reason.

Module 1 recap

Key terms: proposition, connective, truth table, tautology, contradiction, equivalence, premise, conclusion, valid argument, inference rule.

Expected / Exam-Focused Questions: construct a truth table; identify a proposition’s truth value; prove a propositional equivalence; apply an inference rule; distinguish a valid argument from an invalid converse.

Self-test: (1) When is p→q false? (2) Write De Morgan’s law for ¬(p∨q). (3) Is p→q equivalent to its converse q→p? (4) Name the rule in p, p→q ∴ q.

MODULE 2 · SET THEORY · 12 HOURS

Sets, set operations and functions

You will learn: sets and their operations, plus functions as mappings between sets.

Why it matters: sets organise collections of data; functions describe how an input is assigned an output, a central idea in computing.

2.1 Sets

A set is a well-defined collection of distinct objects. The objects are its elements. If a is an element of A, write a∈A; if not, a∉A. Example: V={a,e,i,o,u} is the set of English vowels.

Set-builder notation describes a rule: {x∈ℤ : x is even and 0<x<8}={2,4,6}. The empty set ∅ has no elements. A is a subset of B (A⊆B) if every element of A is also in B. The power set P(A) is the set of all subsets of A.

2.2 Set operations

OperationDefinitionExample for A={1,2,3}, B={3,4}
Union A∪BIn A or B or both{1,2,3,4}
Intersection A∩BIn both A and B{3}
Difference A\BIn A but not B{1,2}
Complement AᶜIn universal set U but not ADepends on U
Cartesian product A×BOrdered pairs (a,b), a∈A,b∈B{(1,3),(1,4),…}
|A∪B| = |A| + |B| − |A∩B|

Subtract the intersection once because adding |A| and |B| counted shared elements twice.

Example: Among 30 students, 18 study Python, 12 study Java, and 5 study both. Number studying at least one = 18+12−5=25.

2.3 Functions

A function f:A→B assigns each element of domain A exactly one element of codomain B. The assigned value is f(x). The range is the set of outputs actually attained; it is a subset of the codomain.

TypeMeaning
Injective (one-to-one)Different inputs have different outputs: f(a)=f(b) implies a=b
Surjective (onto)Every element of the codomain is reached by some input
BijectiveBoth injective and surjective; has an inverse function
Example: f:ℤ→ℤ given by f(x)=x+2 is bijective: each integer output has exactly one integer input, namely y−2. But g:ℤ→ℤ given by g(x)=x² is not injective because g(1)=g(−1); it is not onto ℤ because negative integers are not outputs.
Common mistakes: confusing codomain and range; a relation can assign several outputs to one input, but a function must assign exactly one; check the stated domain before deciding whether a function is onto.

Module 2 recap

Key terms: element, subset, empty set, universal set, power set, union, intersection, complement, domain, codomain, range, injective, surjective, bijective.

Expected / Exam-Focused Questions: simplify set expressions; calculate union/intersection/complement; solve a counting problem using inclusion-exclusion; determine whether a mapping is injective, onto or bijective.

Self-test: (1) If A⊆B, what can be said about elements of A? (2) Compute {1,2}∩{2,3}. (3) Why subtract the intersection in the union formula? (4) Is x↦x² from ℤ to ℤ injective? onto?

MODULE 3 · RELATIONS · 17 HOURS

Relations, representations and equivalence

You will learn: relation properties, ways to represent relations, and equivalence relations.

Why it matters: relations model connections such as “has the same remainder,” “is connected to,” or “is at least as large as.”

3.1 Relations and their properties

A relation R from A to B is a subset of A×B. If (a,b)∈R, write aRb. A relation on A is a subset of A×A.

PropertyTestExample idea
ReflexiveaRa for every a“is equal to”
SymmetricaRb implies bRa“has the same age as”
AntisymmetricaRb and bRa imply a=b“≤”
TransitiveaRb and bRc imply aRc“≤”

Symmetric and antisymmetric are different ideas: symmetric requires the reverse pair; antisymmetric allows both directions only when the two elements are equal.

3.2 Representing relations

For finite sets, represent a relation as a set of ordered pairs, a zero-one matrix, or a directed graph (digraph). In a digraph, elements are vertices and a directed edge a→b represents aRb; a loop at a represents aRa.

Example: A={1,2,3}, R={(1,1),(1,2),(2,2),(3,3)}. Its matrix has rows and columns ordered 1,2,3; put 1 in cells for listed pairs and 0 elsewhere. Loops at all vertices show reflexivity. Since (1,2) is present but (2,1) is absent, R is not symmetric.

3.3 Equivalence relations

An equivalence relation is reflexive, symmetric and transitive. It groups elements into equivalence classes: elements related to a are treated as equivalent under the chosen rule.

Example (same parity on integers): define aRb when a−b is even. Each integer has the same parity as itself (reflexive); if a−b is even, b−a is even (symmetric); if a−b and b−c are even, a−c is even (transitive). The classes are even integers and odd integers.

Equivalence classes form non-overlapping groups that together cover the set. To verify a proposed equivalence relation, check all three properties separately.

Common mistakes: forgetting the domain set; treating a missing reverse edge as symmetric; confusing antisymmetric with “not symmetric”; proving only one or two of the three equivalence properties.

Module 3 recap

Key terms: ordered pair, Cartesian product, relation, reflexive, symmetric, antisymmetric, transitive, matrix representation, digraph, equivalence class.

Expected / Exam-Focused Questions: test properties of a relation; represent a finite relation by a matrix or digraph; show whether a relation is an equivalence relation; find equivalence classes.

Self-test: (1) Is ≤ symmetric on integers? (2) Is equality antisymmetric? (3) Which properties define equivalence? (4) For same parity, name the equivalence classes.

MODULE 4 · MATRICES · 16 HOURS

Matrix types, operations and linear systems

You will learn: matrix definitions and types, symmetric/skew-symmetric matrices, operations, determinants and inverse, and solving non-homogeneous systems by matrix method and Cramer’s rule.

Why it matters: a matrix stores coefficients compactly and provides systematic methods to solve several linear equations together.

4.1 Definitions and types of matrices

A matrix is a rectangular array of numbers. Its order is rows × columns. A square matrix has the same number of rows and columns; a diagonal matrix has zero entries off the main diagonal; an identity matrix I has 1s on the diagonal and 0s elsewhere; a zero matrix has all entries 0.

For a square matrix A, transpose Aᵀ swaps rows and columns. A is symmetric if Aᵀ=A and skew-symmetric if Aᵀ=−A. In a real skew-symmetric matrix diagonal entries must be zero, since aᵢᵢ=−aᵢᵢ.

4.2 Matrix operations, determinant and inverse

Addition/subtraction require matrices of the same order and operate entry by entry. Scalar multiplication multiplies every entry. Matrix multiplication AB is defined when columns of A equal rows of B; it is generally not commutative (AB may differ from BA).

For A=[[a,b],[c,d]], det(A)=ad−bc

A square matrix is invertible when its determinant is non-zero. Its inverse satisfies AA⁻¹=A⁻¹A=I.

A⁻¹ = (1/(ad−bc)) [[d,−b],[−c,a]], when ad−bc ≠ 0
Step-by-step inverse: A=[[2,1],[1,1]]. Determinant=2×1−1×1=1. Swap diagonal entries and negate off-diagonals: [[1,−1],[−1,2]]. Divide by 1, so A⁻¹=[[1,−1],[−1,2]]. Check AA⁻¹=I.

4.3 Solve a non-homogeneous system: matrix method and Cramer’s rule

A non-homogeneous linear system has form AX=B with at least one non-zero constant in B. If A is invertible, X=A⁻¹B gives the solution.

Example: Solve 2x+y=5 and x+y=3. Matrix form: [[2,1],[1,1]][[x],[y]]=[[5],[3]]. From A⁻¹=[[1,−1],[−1,2]], X=A⁻¹B=[[5−3],[-5+6]]=[[2],[1]]. Answer x=2, y=1. Check both original equations.

Cramer’s rule solves a square system when D=det(A)≠0. Replace column i of A with the constants column B to obtain Dᵢ; then xᵢ=Dᵢ/D.

For 2x2: D=|a b; c d|;   x=Dₓ/D;   y=Dᵧ/D
Same example: D=|2 1;1 1|=1. Dₓ=|5 1;3 1|=2; Dᵧ=|2 5;1 3|=1. Therefore x=2/1=2 and y=1/1=1.
Common mistakes: matrix multiplication order/dimensions; assuming AB=BA; inverse when determinant is zero; sign errors in 2×2 determinant; replacing the wrong column in Cramer’s rule; skipping a substitution check.

Module 4 recap

Key terms: order, square matrix, transpose, identity, determinant, inverse, singular, non-singular, coefficient matrix, non-homogeneous system.

Expected / Exam-Focused Questions: identify matrix types; test symmetric/skew-symmetric; compute products/determinants/inverse; solve a system by inverse matrix and Cramer’s rule.

Self-test: (1) What must be true for AB to exist? (2) Is matrix multiplication commutative? (3) When does a 2×2 inverse exist? (4) What is the diagonal of a real skew-symmetric matrix? (5) Check x=2,y=1 in the example system.
